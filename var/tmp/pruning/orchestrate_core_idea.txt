┌─────────────────────────────┐
│ host: ./var/tmp             │  ← one bind mount, shared by every container
│   path_sets/                │
│   testing-dir/<lang>/...    │
│   opt/core/config/          │
└──────────────┬──────────────┘
               │
       ┌───────┴──────────────┐
┌──────▼───────────┐   ┌──────▼───────────┐
│ prune_python     │   │ prune_java       │
│ pytest, pip, …   │   │ maven, gradle, … │
│ prunes python    │   │ prunes java      │
└──────────────────┘   └──────────────────┘
               │
┌──────────────▼──────────────┐
│ orchestrate                 │  starts once both have finished successfully
└─────────────────────────────┘


    Every container mounts the same host directory, read-write, at /var/tmp, so they all
    see the same path_sets and opt/core.

    Each prune container writes one <lang>_<exercise>.paths (and .json) per exercise into
    path_sets.

    The orchestrate service then folds each language's results into <lang>_union.paths,
    merges the languages, and writes BaseLanguage-<lang>.cfg and TailPhobos.cfg into
    opt/core/config. Copying them into core/config is a reviewed step of its own.

No network between the containers and no docker cp: the shared bind mount is the only channel.
